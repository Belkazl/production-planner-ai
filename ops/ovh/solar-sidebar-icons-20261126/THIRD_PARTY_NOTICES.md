# Solar Linear navigation icons

Icon artwork: Solar Linear, by 480 Design. [Source collection](https://www.svgrepo.com/collection/solar-linear-icons/); [original Solar icon set](https://www.figma.com/community/file/1166831539721848736).

License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The original 24×24 vector paths are obtained from the pinned @iconify-json/solar package at build time. Changes: rendered at the existing navigation icon size and inherit navigation color. No modification to vector geometry, external runtime fetch, optimizer, authentication, or model data.

The candidate workflow is read-only with respect to production code and uses an isolated synthetic account. The separately gated release workflow is triggered by an explicit DEPLOY_APPROVED marker only after ongoing optimization is finished. It patches only authenticated HTML, backs up the previous source, verifies other runtime files are unchanged, and rolls back on failed acceptance.
